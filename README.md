# Palmera Bay — Open World Crime

Jax Carter is fresh out of county jail and broke in Palmera Bay, a sun-soaked port city of
neon, palm trees and bad decisions. Mia Torres has work for him — four jobs, from stealing
his first set of wheels to a vault heist the whole city is talking about, The Bay Job.
Stay out of the cuffs, get rich, take the city.

## What is in the game

- A full 3D open world: a 7×7-block city with towers, palms, street lights, a golden
  Palmera Trust tower, a lighthouse on the south-west shore, the Strip, the Marina,
  Old Town, Palm Heights, Downtown and the Harbor — plus the sea, the beach and
  drifting clouds.
- On foot and behind the wheel: walk, run and jump, or steal any of 10 parked cars —
  or carjack one of 14 traffic cars (the driver runs, the cops notice).
- A wanted system, 0–5 stars: police interceptors with flashing light bars and foot
  officers who chase, ram and grab you. Lose them for 9 seconds to clear the heat;
  get caught and pay $300 bail, go down and pay $200 at the hospital.
- Combat: fists, a P9 pistol and a VK-9 SMG, with tracers, armor that absorbs 60% of
  each hit, and health / armor / cash / ammo pickups scattered around the city.
- Four chained jobs from Mia Torres and Dante Cole — Borrowed Wheels ($500),
  The Package ($800), Heat on the Strip ($1,200) and The Bay Job ($2,500) — with a
  golden target marker, timed deliveries, a vault hold and a 3-star escape.
- HUD with cash, health and armor bars, wanted stars, a clock with the district name,
  a mission objective bar, banners, dialogue, toasts, a speedometer, a weapon readout
  and a round live minimap with a rotating player arrow.
- Synthesized sound only — gunshots, sirens, engine hum, a two-tone police siren and
  an ambient pad, all generated by WebAudio. No audio files, no network requests.
- Autosave to local storage every 15 seconds, on pause and on job completion, with
  Continue Saved Game on the title screen.

## Controls

| Key | Action |
| --- | --- |
| W A S D | Move / drive (W accelerate, S brake/reverse, A/D steer) |
| Shift | Run on foot |
| Space | Jump |
| Mouse | Look around (click the game to capture the pointer) |
| Click | Shoot (hold for the SMG) |
| E | Enter / exit a car, steal a parked car, carjack traffic |
| 1 / 2 / 3 | Fists / P9 pistol / VK-9 SMG |
| R | Reload |
| N | Start the next job |
| C | Toggle close / chase camera |
| P or Esc | Pause |
| H | Hide / show the HUD |
| M | Mute / unmute |

## How to play

Serve the game locally and open it in desktop Chrome:

```sh
node serve.ts
# open http://localhost:8080
```

Or serve `game/` with any static server. The game runs with zero network requests:
everything it loads is a file under `game/` (three.js 0.160.0 is vendored at
`game/vendor/three.min.js`).

## Files

- `game/index.html` — page shell, HUD, screens, import map
- `game/src/main.js` — boot, the one game loop, save/load, screens
- `game/src/config.js` — constants, city layout, mission data, pickup spots
- `game/src/random.js` — seeded random generator
- `game/src/input.js` — keyboard and mouse
- `game/src/audio.js` — synthesized WebAudio sound
- `game/src/city.js` — the city, buildings, palms, lights, collision
- `game/src/vehicles.js` — cars, driving, traffic, carjacking
- `game/src/people.js` — pedestrians and foot officers
- `game/src/police.js` — wanted level, chases, arrests, escape
- `game/src/missions.js` — the four-job chain
- `game/src/combat.js` — shooting, punching, tracers, pickups, damage
- `game/src/hud.js` — HUD and minimap
- `game/src/player.js` — on-foot movement and cameras
- `game/src/shots.js` — staged screenshot scenes
- `main.ts` — entrypoint: copies `game/` + `screenshots/` and writes `dossier.json`
- `serve.ts` — local static server for `game/` on port 8080
- `shots.json` — the four staged screenshots
- `screenshots/` — `start.jpg`, `drive.jpg`, `chase.jpg`, `mission.jpg`
